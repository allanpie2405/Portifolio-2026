# 💻 Portfólio Pessoal

Bem-vindo ao meu portfólio pessoal! 🚀

Este projeto foi desenvolvido com o objetivo de apresentar um pouco sobre mim, minha formação, meus interesses e os projetos que venho desenvolvendo durante minha trajetória na área de tecnologia.

## 👨‍💻 Sobre mim

Sou estudante de **Engenharia de Software** e tenho interesse principalmente em **desenvolvimento web**.

Atualmente, venho aprimorando meus conhecimentos em desenvolvimento Front-End e Back-End, criando projetos práticos para colocar em prática os conceitos que estudo.

Tenho como objetivo continuar evoluindo como desenvolvedor, explorando novas tecnologias e construindo projetos cada vez mais completos.

## 🛠️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/allanpie2405/Portifolio-2026-.git
```

### 2. Entre na pasta do projeto

```bash
cd Portifolio-2026-
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Depois, acesse o endereço informado pelo Vite no terminal.
